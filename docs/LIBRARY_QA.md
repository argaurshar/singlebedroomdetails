The user authorized a preset library and the previously discussed improvements. Implementation
is on `feat/preset-library`; the existing cabinet/bedroom are preserved. Nothing was merged or
publicly deployed by this task. This is a tested review build with the renderer limitations below,
not a claim of complete geometric or fabrication certification.

`npm test`: **43 tests passed**, including 22 new library tests and the 21 preserved room/cabinet
checks. `python3 tests/library-browser.py`: **10 acceptance groups passed**, with 53 captures.
`tests/library-export.py` and `tests/library-performance.py` passed their separate checks.
The desktop figures, mobile assembled/exploded/connection captures, sections, printed
sheet, exported SVG and video frames were actually opened and inspected. Representative evidence
is committed under [`evidence/library`](evidence/library); all individual captures remain in the
local `.test-artifacts/library` directory and can be regenerated by the scripts.

Canonical seek remounts the SVG from cached geometry before rendering the requested pose, so
it does not inherit previous face attributes or tie order. Live animation keeps its nodes.
Shuffled seeks produce identical SVG markup. Chromium's image rasterization can vary by up to
5/255 per channel despite identical markup; the screenshot comparison allows only that small
colour difference, not shape or position changes.

## Extended turning audit — limitations, not a clean pass

The completed scoped command was:

```sh
node scripts/audit-library.mjs --only=order,rigid,swept,posed,routes,coverage
```

It scans a full rotation, the story and assembly workshop, with sampled, random and event states.
For all seven presets it reported **zero separation failures, unseparated pairs, cycles, forced
orders, rigid collisions, swept/posed intersections, route or coverage failures**.
It also reported **51 unresolved order-change warnings**: bedside 8, console 0, desk 5, coffee 4,
bookcase 2, lamp 32. These are actual nonzero toolkit diagnostics; the command exits unsuccessfully
and is not labelled an audit pass. The affected pair/state records are committed in
[`geometry-audit-summary.json`](evidence/library/geometry-audit-summary.json).

Warnings involve touching drawer edges, runner webs/lips, shelf-block contacts, a bookcase
back/side contact and adjacent shade panels. Seventeen distinct affected pairs were captured
immediately before/after their story event and visually inspected. No large object jump was
visible in those paired views; that does not invalidate the warnings or prove every intermediate
pixel correct. The largest reported overlap area is approximately 44.76 toolkit pixel² at a
bookcase contact. No vendored diagnostic code, tolerance or failure threshold was changed.

A full pixel-level continuity/depth run and a separate depth-oracle run were attempted but did
not finish within this task's extended validation window. Their partial progress is not counted
as successful coverage. The exhaustive audits remain outstanding; rerun `npm run audit:library`
or use `--preset=bedside` for one study. This is a scope/time limitation of this review, not a
reported network or browser blockage. The scripted sampled/browser checks above are completed.

## Performance and browser limits

A 120-frame desk sample measured approximately **60 fps** at 1440 px with no CPU throttle
(95th-percentile render work 2.5 ms), and **25.2 fps** at 390 px with Chromium's 4× CPU slowdown
(95th-percentile render work 11.5 ms). This is an emulation, not a physical-phone benchmark.
Performance varies with device and object; no universal 60 fps promise is made. Explicit
recording is slower than normal playback because each exported frame is serialized and decoded.

Only system Chromium was exercised. Safari, Firefox and physical iOS/Android devices remain
untested. Blob Web Workers and MediaRecorder support vary. Video export is silent, records the
object plus captions, stops when the page is hidden, and requires the tab to stay visible.
Chromium WebM does not provide a container duration field; validation used the final packet's
presentation timestamp. MP4 fallback depends on browser support and was not tested here.

The managed browser blocks `file://` navigation; standalone files were tested over local HTTP
without external requests. Direct double-click opening in another browser remains unverified.
If a browser blocks local workers, the preset studies still open; use local HTTP for editing.
PDF is the browser Print/Save as PDF flow, not a CAD/dimensioned fabrication deliverable.

## Build and deployment

`npm ci` installs pinned build-only esbuild. `npm run build` produces the room, original cabinet,
then library. `dist/index.html` and `dist/library.html` are identical. `dist/library.zip` includes
both preserved studies and the Anatomy MIT licence. GitHub Actions now installs the lockfile
before tests/build and still publishes only `main`.

The GitHub CLI credential reports failed authentication in this cloud environment. PR creation
is therefore not claimed. The branch/download and review URL are provided at handoff if the
Git transport push succeeds. Merging and live GitHub Pages deployment remain user actions.
