## Exhaustive geometry audit — qualified result

The non-quick Anatomy run completed in 965.59 seconds with all check categories enabled:
1,041 order states, 1,081 posed states, 800 continuity halving checks and 12,760 depth pairs
across 35 depth-oracle states. Configuration: 300 random order samples, 3° orbit sweep, 0.1 s
story frames, 12 primary depth angles and up to 12 order-event depth probes. The base contact
and support audit reported no findings.

The turning audit reported zero separation failures, unseparated pairs, cycles, forced orders,
posed collisions, rigidity failures, depth errors or continuity failures. **It did not return an
unqualified pass:** 32 rail-web/lip order-change warnings remain, with reported overlap areas
5.68–5.73 px² at the audit projection. No checks or thresholds were disabled to hide these.

Warnings occur near four orbit angles and at story times 3.268, 3.472, 6.922 and 7.012 seconds.
An additional browser visibility experiment hid only the flagged rail pieces at each reported
pose. Four poses were pixel-identical; four showed the rail pieces through narrow cabinet
reveals (217–256 changed pixels when hiding entire pieces). This experiment identifies their
visibility; it does not prove the ordering changes themselves harmless. These remain an open
rendering limitation, especially for arbitrary user-controlled orbit angles. The ordinary
browser suite and motion heuristic passing must not be presented as a clean full-audit pass.

Retained [full audit data](evidence/cabinet/audit.json), [log](evidence/cabinet/audit-log.txt) and
[visibility experiment](evidence/cabinet/audit-visibility.json). The pinned toolkit was not modified.

## Playback performance

Measured real requestAnimationFrame intervals while playing the turn, runner and drawer
construction chapters, with the geometry audit suspended to avoid concurrent CPU load.

| Viewport / CPU profile | Median frame interval | 95th percentile |
| --- | ---: | ---: |
| 1440 × 1100, normal CPU | 16.7 ms (~60 fps) | 33.4 ms |
| 390 × 844, normal CPU | 16.7 ms (~60 fps) | 16.7 ms |
| 390 × 844, 4× CPU throttle | 66.7 ms (~15 fps) | 99.9 ms |

The throttled profile is a known limitation, not a 60 fps pass. These are cloud Chromium
measurements, not tests on a physical phone. Playback limits its time step under load to avoid
large position jumps, so it can take longer than the nominal story time on slower hardware.

## Limits

- This is detailed illustrated SVG with true 3D reprojection, not photorealistic furniture rendering.
- Runner, bearing and joinery proportions are teaching assumptions, not a manufacturer's mechanism,
  workshop drawing, load rating or construction certification. Exploded gaps are presentation only.
- Native `file://` navigation is blocked by managed-browser policy. HTTP operation with no required
  external requests passed; direct opening of the downloaded HTML in a separate browser remains unverified.
- No narrated video or audio export was generated. The working app is the deliverable.
- No claim of matching the reference's implementation or all of its visual quality is made. The
  user-supplied recording was visually inspected; the older website REA investigation is documented separately.
